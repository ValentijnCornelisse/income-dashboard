# Income Dashboard

A modern income tracking dashboard for small businesses. Set income targets and track sales in real-time with a beautiful, responsive interface.

## Features

- 🎯 Set and track income targets
- 💰 Add sales and watch the remaining goal count down
- 📊 View sales history
- 🎨 Modern, professional design with company branding
- 📱 Fully responsive design
- 💾 Persistent data storage

## Company Colors

- Black: #000000
- Slate: #7D8CA3
- Green: #48BF84

## Setup

1. Clone the repository
2. Ensure you have PHP installed
3. Upload to your web server or run locally with `php -S localhost:8000`
4. Access the dashboard in your browser

## Files

- `index.php` - Main dashboard application
- `styles.css` - Styling and layout
- `script.js` - Interactive features
- `data.json` - Persistent data storage

## Usage

1. Click "Set Target" to set your income goal
2. Click "Add Sale" to record a sale
3. Watch your remaining goal count down in real-time
4. View your sales history and reset when needed
